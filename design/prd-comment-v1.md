# 简历分析 AI 工具 PRD

## 产品名称

**简历透视镜** (ResumeLens)

---

## 1. 产品概述

### 1.1 产品定位

面向猎头、HR 的 AI 简历分析工具，将"信息处理"和"初步分析"外包给 AI，让人只保留最终判断权。

### 1.2 核心价值

- **效率提升**: 替代 3-4 名初级顾问的简历筛选工作
- **判断显性化**: 将直觉判断转化为结构化输出
- **按价值收费**: 从"按简历数量"转为"按判断质量"

### 1.3 目标用户

| 用户类型 | 痛点 | 需求 |
|----------|------|------|
| 资深猎头 | 80%判断靠直觉，团队工作无效 | 结构化分析、对齐判断 |
| HRBP | 简历量大、筛选耗时 | 快速初筛、风险提示 |
| 小型猎头公司 | 养不起专业团队 | 低成本获得专业分析 |

## 3. 功能详细说明

### 3.1 JD 拆解模块

#### 输入
- JD 文本（粘贴或上传文档）
- 补充信息（可选）：薪资范围、团队背景

#### 输出
```json
{
  "硬性要求": {
    "学历": "本科及以上",
    "经验": "5年以上",
    "技能": ["Python", "分布式系统", "高并发"]
  },
  "隐性需求": {
    "管理经验": "需带10人团队",
    "风格": "结果导向、狼性文化",
    "潜力": "能适应从0到1创业节奏"
  },
  "潜在冲突": [
    "薪资可能倒挂现有团队",
    "汇报对象技术背景弱，需强沟通"
  ],
  "用人风险": [
    "该层级候选人普遍在职，招聘难度高",
    "创业公司背景优先，否则可能水土不服"
  ]
}
```

#### 核心 Prompt 要点
- 拆解显性需求 vs 隐性需求
- 识别自相矛盾的要求
- 预警用人风险

---

### 3.2 简历解析模块

#### 输入
- 简历文件：PDF、Word (.doc/.docx)、图片
- 或直接粘贴简历文本

#### 输出
```json
{
  "基础信息": {
    "姓名": "张三",
    "工作年限": "8年",
    "当前职级": "技术专家/架构师"
  },
  "成长轨迹": {
    "职级跃迁": [
      {"时间": "2016", "公司": "A公司", "职级": "工程师"},
      {"时间": "2018", "公司": "B公司", "职级": "高级工程师"},
      {"时间": "2020", "公司": "C公司", "职级": "技术经理"},
      {"时间": "2023", "公司": "D公司", "职级": "架构师"}
    ],
    "稳定性评分": "7/10",
    "空窗期": ["2020.03-2020.07 4个月"]
  },
  "能力图谱": {
    "硬技能": ["Go", "Kubernetes", "微服务", "高并发"],
    "软技能": ["团队管理", "跨部门协调", "技术规划"],
    "行业经验": ["金融", "电商", "AI"]
  },
  "决策风格": {
    "类型": "稳定进取型",
    "特征": [
      "职级稳步上升，非跳跃式",
      "跳槽周期约2-3年，较为稳定",
      "倾向于技术深度而非管理路径"
    ]
  },
  "风险信号": [
    "最近一次跳槽仅1年，可能不稳定",
    "空窗期4个月，需确认原因"
  ]
}
```

#### 核心 Prompt 要点
- 语义级分析，非简单关键词提取
- 识别决策风格（稳定型/冒险型/渐进型）
- 主动识别风险信号

### 3.3 匹配对齐模块

#### 输入
- JD 拆解结果
- 候选人解析结果

#### 输出
```json
{
  "匹配度": {
    "综合评分": "82/100",
    "硬性匹配": "90%",
    "隐性匹配": "75%"
  },
  "结论": {
    "标签": "推荐",
    "置信度": "高",
    "理由": "技术深度匹配度高，管理经验略弱"
  },
  "优势": [
    "Go + 微服务经验与JD要求高度匹配",
    "有从0到1架构经验，符合创业公司需求",
    "行业经验金融+电商，覆盖目标行业"
  ],
  "风险": [
    "团队管理经验仅3年，可能不足以带10人",
    "最近跳槽周期短，需确认稳定性动机"
  ],
  "追问引导": [
    "候选人为何离开上一家公司？",
    "对管理岗位的兴趣程度如何？",
    "期望的薪资范围是多少？"
  ]
}
```

#### 核心 Prompt 要点
- 量化匹配度评分
- 给出明确结论（推荐/谨慎/高风险）
- 提供追问清单，帮助猎头深度对谈

```

   30秒         10秒          30秒          15秒           随时查看
```

### 4.2 页面结构

| 页面 | 功能 |
|------|------|
| 首页/分析台 | 快捷分析入口、最近分析记录 |
| JD 库 | 管理 JD 模板、查看历史 JD |
| 简历库 | 上传/管理简历、查看解析结果 |
| 分析报告 | 查看完整匹配报告 |
